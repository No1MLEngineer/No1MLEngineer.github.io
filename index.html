What it does

A second pair of eyes that never gets tired.

Totals hide contradictions. Haql tools run numbered, deterministic rules over the file you already export — then hand you a row number instead of a hunch. No database, no login, no pipeline to set up.

01 / Traceable

Every finding has an address

A stable rule ID, the well, the date, the 1-indexed source row, the observed value and the input SHA-256. Anyone can reopen the file and re-verify the run against the same bytes.

02 / Offline

Nothing leaves your machine

The binaries make no network calls: no telemetry, no upload, no activation server. Reservoir and MRV data frequently cannot leave your infrastructure, so the tool never asks it to.

03 / Deterministic

Same input, same answer

Identical input bytes and configuration produce identical findings on every machine. The embedded run timestamp varies; the findings do not. Rule IDs are permanent — adding a rule never renumbers an existing one.

04 / Honest

It refuses to guess

No declared unit means no unit-dependent check runs, and the report names the gap. A confidently wrong unit is worse than no check at all.

Engineering & validation

Trust is a property of the build, not the brochure.

The design constraints are deliberate: no network, no writes, no model, no guess. What follows is the part most tools leave out — how the claims are checked, and what is still open.

  • Never corrupt source data. Read-only by construction. Correcting requires knowing which of two contradictory fields is wrong, and the data cannot supply that.
  • Never guess. Units are declared by you and recorded in the report as your declaration.
  • Never be untraceable. Every finding ties to a stable rule ID, a row you can open in an editor and a hash of the input.

One field is a starting point, not a general guarantee, and we will not claim otherwise. The sample audit report is downloadable below.

Benchmarks published with the misses

haql-rs runs a full two-phase forecast in about 35 seconds, on one CPU thread: injector pressure 4,800 psi against a 4,801 psi reference; producer pressure 3,751 psi against 3,840 psi (−2.3%). Producer gas saturation came out at 5.0% against 8.6% — a 3.6-point gap listed as open work, not smoothed over.

Measured on a single laptop run. The reference is a black-oil deck, not a field-wide guarantee.

About Haql Labs

Why you should hand over a month of data to a stranger.

Fair question. Here is the actual answer.

Every Haql tool ships as a single self-contained binary that runs entirely on your machine, offline, with no installer and no Python to configure. It never opens a network connection. The rules are numbered permanently: adding a rule never renumbers an existing one, because audit logs referencing them are already in other people's hands.

  • Never corrupt source data. The tools are read-only by construction. They cannot auto-correct, because correcting requires knowing which of two contradictory fields is wrong, and the data cannot supply that.

FAQ

Straight answers.

Does it use AI?

No. Every rule is deterministic arithmetic on your data — comparisons, monotonicity checks, medians. No model, no network call, no language model anywhere in the packages. Running the same file twice gives the same answer.

Does my data leave my computer?

Run locally, nothing leaves your machine — the code makes no outbound calls. If you use the free sample check instead, you are choosing to email us the file, and you can ask for it back anonymised or deleted.

What do I need to install?

Nothing, if you use the free sample check. To run the tools yourself, download the binary for your OS from the downloads page and run it — there is no Python to install and nothing else to configure.

Which product do I need?

QC for the daily or monthly export you already have; closeout when the period needs to be locked; haql-45q if you report carbon capture and storage; haql-emission if you file a GHG inventory or owe EU ETS allowances; haql-rrc before a Texas PR filing; haql-dataroom before an acquisition closes. Units and Coords are free libraries you use from your own code.

Can I try it free?

Yes. Email one month of data — anonymised if you prefer — and you get the full report at no cost. Evaluation use of the CLI also needs no license key.

How is it licensed?

haql-qc, haql-closeout and haql-45q are proprietary: running them commercially requires a license. Licenses are signed ed25519 tokens carrying company, tier, seats and expiry, verified entirely offline against an embedded public key — no activation server, no phone-home. haql-units and haql-coords are MIT and need no license at all.

Will it decide whether my well is performing?

No. Plausibility is not performance. It flags a rate above the configured plausibility ceiling — not because the rate is unusual, but because it cannot be real in your facility. It refuses questions outside its competence.

Is a revoked license still verified offline — why?

Because nothing inside the token records that fact. A revoked license verifies correctly until it expires, unless the caller checks a registry. We would rather state that limit than imply revocation works offline when it does not.

Send us a month of data.

Tell us which field, anonymise it if you need to, and mention anything unusual about how your operator reports — a sign convention, a units quirk, a column that means something other than its name. That context is usually where the real findings hide.
