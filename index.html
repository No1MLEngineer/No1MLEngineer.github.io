How it works

One step added. Nothing replaced.

No change to how you capture or account for production. Export the file you already have, run the check, and decide what to fix in your source of truth.

  1. ExportYour production, monitoring or MRV data — no change to your capture or accounting system.
  2. RunRun the CLI yourself offline, or email the file for a free sample check. Both use the same rules.
  3. ReviewEvery finding names the rule, the well, the date and the 1-indexed source row.
  4. FixYou correct your source of truth. The tool never writes to your file.

Read-only in both directions · no network call · no telemetry · no upload · no model.

Trust & FAQ

Why hand a month of data to a stranger.

Every Haql tool is a single self-contained binary that runs entirely on your machine, offline, with no installer and no Python. It never opens a network connection. The rules are numbered permanently — adding a rule never renumbers an existing one.

  • Never corrupt source data. Read-only by construction. Correcting requires knowing which of two contradictory fields is wrong, and the data cannot supply that.
  • Never guess. Units are declared by you and recorded in the report as your declaration.
  • Never be untraceable. Every finding ties to a stable rule ID, a row you can open, and a hash of the input.

haql-qc is validated against one public field — Equinor's Volve dataset, 15,634 daily and 526 monthly rows, producing 80 findings. One field is a starting point, not a general guarantee, and we will not claim otherwise. Download the sample audit report.

Does it use AI?

No. Every rule is deterministic arithmetic on your data — comparisons, monotonicity checks, medians. No model, no network call. Running the same file twice gives the same answer.

Does my data leave my computer?

Run locally, nothing leaves your machine — the code makes no outbound calls. If you use the free sample check, you choose to email us the file, and you can ask for it back anonymised or deleted.

What do I need to install?

Nothing, if you use the free sample check. To run the tools yourself, download the binary for your OS from the downloads page — no Python, nothing else to configure.

How is it licensed?

The commercial tools are proprietary: running them requires a signed Ed25519 token carrying company, tier, seats and expiry, verified entirely offline. No activation server. haql-units and haql-coords are MIT and need no license.

Send us a month of data.

Tell us which field, anonymise it if you need to, and mention anything unusual about how your operator reports — a sign convention, a units quirk, a column that means something other than its name.
