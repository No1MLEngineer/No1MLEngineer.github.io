Download

Download a tool. Run it offline.

Each binary tool ships as a single self-contained file — no Python to install, no dependencies to resolve, no installer. Unzip it, run it. The simulation audit is a service: send a deck and run, get a signed report. No tool opens a network connection.

Choose your platform Or send me a month — free check

Evaluation: every tool runs for 30 days with no license key. After that, point it at a signed license file — verified entirely offline, nothing to activate online.

unzip and run
# macOS / Linux — .zip download, then
unzip haql-qc-0.4.1-macos-arm64.zip
./haql-qc --version
haql-qc 0.4.1 (ruleset 1.2.0)

./haql-qc -i production.csv -r audit.json

# Windows — unzip, then in PowerShell
.\haql-qc.exe -i production.csv -r audit.json

Every zip contains the binary, a QUICKSTART.txt, the product README.md and its LICENSE. Nothing else to install.

Inside every download

One binary, four files, no source tree.

The executable

haql-qc (macOS/Linux) or haql-qc.exe (Windows) — the whole tool compiled into one file. No Python runtime, no site-packages, nothing to pip-install on the target machine.

The paperwork

QUICKSTART.txt — the two commands you need. README.md — what the tool checks. LICENSE — the terms, including the 30-day evaluation.

No network calls

The binary is built to run air-gapped. Reservoir and MRV data frequently cannot leave your infrastructure, so the tool never asks it to.

Read-only by construction

It cannot auto-correct your data; correcting needs to know which of two contradictory fields is wrong, and the file cannot say. It only reports.

Deterministic

Same input bytes and configuration, same findings — every run, on every machine. The embedded run timestamps vary; the findings do not.

Offline licensing

A signed ed25519 token carrying company, tier, seats and expiry, verified against an embedded public key. No activation server, no phone-home.
